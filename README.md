# Overview

This portfolio serves as my personal digital presence, designed to professionally present my academic journey, technical competencies, software projects, certifications, and practical experience in cybersecurity and software development.

The application follows modern web development principles with a strong emphasis on responsive design, performance, accessibility, and user experience. It incorporates smooth animations, interactive components, and a cybersecurity-inspired visual theme to create an engaging yet professional interface.

The portfolio reflects my passion for building secure, scalable, and innovative applications while continuously expanding my knowledge in cybersecurity, artificial intelligence, cloud technologies, and full-stack web development.

# Installation

Clone the repository

```bash
git clone https://github.com/agilanj/agilan-portfolio.git
```

Navigate to the project directory

```bash
cd agilan-portfolio
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Visit

```
http://localhost:3000
```
